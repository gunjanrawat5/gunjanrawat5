## 📌 Featured Projects

### 🔐 Double Ratchet Diffie-Hellman Chat
**Next.js, TypeScript, Supabase, PostgreSQL, Web Crypto API, IndexedDB**

Built an end-to-end encrypted messaging application inspired by Signal’s Double Ratchet and Diffie-Hellman key exchange.

- Implemented browser-side encryption using identity keys, signed prekeys, one-time prekeys, and X3DH-style shared secret exchange
- Used Supabase Auth, Realtime updates, and PostgreSQL for user/session/message data
- Stored private cryptographic keys securely in IndexedDB
- Designed database schemas for profiles, identity keys, signed prekeys, one-time prekeys, conversations, and encrypted messages

---

### 🛒 Java E-commerce Backend
**Java, Spring Boot, JPA/Hibernate, MySQL/PostgreSQL, REST APIs, WebSockets, JWT**

Built a backend system for an e-commerce platform with authentication, product management, cart operations, order workflows, and real-time updates.

- Developed REST APIs for users, products, carts, orders, and inventory workflows
- Implemented JWT-based authentication and structured backend validation
- Used JPA/Hibernate for relational database modeling and transactional data access
- Added WebSocket-based real-time updates for order status, inventory changes, or user/admin notifications

---

### 🎬 FlixAI
**React.js, Redux, Firebase, Tailwind CSS, Google Gemini API**

Built a Netflix-inspired movie discovery platform with AI-powered search and recommendation features.

- Integrated Google Gemini API for natural language movie search
- Built responsive UI components using React.js and Tailwind CSS
- Managed application state using Redux Toolkit
- Used Firebase for authentication and app data handling

---

### 🧠 Multilingual LLM Knowledge Editing Evaluation
**Python, RAG, ROME, MEMIT, IKE, LLaMA, Mistral, Qwen**

Developed research pipelines for evaluating factual knowledge edits and ripple effects across multilingual prompts.

- Processed 500+ factual edits across English, Hindi, Marathi, Telugu, and Kannada
- Built automation scripts for large-scale experiments across multiple LLMs
- Implemented evaluation modules for edit accuracy, consistency, and unintended side effects
- Added structured logging, resumable execution, and CSV-based result tracking
